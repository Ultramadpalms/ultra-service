# Подготовка zeekrexpert.ru

Основной адрес: https://zeekrexpert.ru/

В локальной версии подготовлены canonical, og:url, путь превью изображения на новом домене и sitemap.xml. Сохранена блокировка индексации: meta robots noindex,nofollow и robots.txt Disallow: /.

DNS, HTTPS и внешние перенаправления ещё НЕ настроены. Для следующего шага нужны название регистратора, выбранный хостинг и безопасный доступ к соответствующему сервису либо внесение выданных записей владельцем. Пароли и токены в чат не присылать.

После выбора хостинга:

1. Разместить содержимое dist в корне сайта.
2. Привязать zeekrexpert.ru через панель хостинга и внести выданные DNS-записи. Существующие почтовые записи сохранить.
3. Включить сертификаты для zeekrexpert.ru, www.zeekrexpert.ru и дополнительных доменов, если они используются для перенаправления.
4. Настроить 301 или 308 с www на https://zeekrexpert.ru/; с myzeekr.ru и fixzeekr.ru также на основной адрес. DNS сам по себе HTTP-перенаправление не выполняет. Неизвестные старые пути проверять отдельно, не направлять их на отсутствующие страницы.
5. Проверить телефонные ссылки, контакты, фото, главную и изображения превью на HTTPS.
6. Только после готовности публичного сайта удалить meta robots noindex,nofollow и заменить robots.txt на:

```
User-agent: *
Allow: /
Sitemap: https://zeekrexpert.ru/sitemap.xml
```

7. Подключить инструменты поисковых систем по решению владельца.

Адреса DNS и параметры сертификатов зависят от выбранного хостинга; непроверенные значения в проект не внесены.
